# レシート家計簿

レシート画像をアップロードすると、Claude API(Claude Haiku 5.5)が商品名・金額・日付を読み取り、カテゴリ別に自動分類して集計する家計簿 Web アプリです。

## 機能

- レシート画像の読み取り(読み取り結果は登録前に確認・修正できます)
- 商品ごとのカテゴリ自動分類(食費・外食・日用品・交通費・衣服・医療・健康・趣味・娯楽・その他)
- カテゴリ別の円グラフ(月ごとに切り替え可能)と月別の棒グラフ
- データはブラウザのローカルストレージに保存されます

## セットアップ

```bash
npm install
cp .env.example .env   # .env を開いて ANTHROPIC_API_KEY を設定
npm run dev            # http://localhost:5173 を開く
```

API キーはバックエンド(Express)だけが使用し、ブラウザには送られません。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | バックエンド(:3001)とフロントエンド(:5173)を同時に起動 |
| `npm test` | テストを実行 |
| `npm run build` | フロントエンドを `dist/` にビルド |
| `npm start` | ビルド済みのアプリをバックエンドから配信(http://localhost:3001) |
